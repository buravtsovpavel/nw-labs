### Подготовка

По данной топологии(учитывая, что в зонах 24 и 26 по одному мрашрутизатору, а оба маршрутизатора из зоны 2222 соединены линками с другими зонами) может быть два варианта распределения уровней маршрутизаторов:

1. Все маршрутизаторы работают как L1L2.
- В этом случае все четыре маршрутизатора настроены на работу в обоих уровнях — L1 и L2.
- Они могут обмениваться маршрутами внутри своих зон (L1) и между зонами (L2).
- Такая конфигурация обеспечивает полную маршрутизацию между всеми зонами и сегментами.
2. Р23 и R25 работают как L1L2, а R24 и R26 — как только L2:
- R23 и R25 настроены на работу в обоих уровнях (L1 и L2), что позволяет им обмениваться маршрутами внутри своей зоны и с другими зонами.
- R24 и R26 — только L2, поэтому они участвуют только в межзоновой маршрутизации, не обмениваясь маршрутами внутри своих зон. (но это в такой топологии и не нужно)

### Выберем первый вариант - все маршрутизаторы будут L1L2.

на R25 и R26 временно останутся статические маршруты до подсетей пользователей (172.16.0.0/16), до Лабытнанги (R27) и на R25 отслеживание проверки доступности IP-адреса 200.50.0.33 через технологию IP SLA которое настраивалось в лабораторной работе PBR (на случай если e0/3 на R25 упадёт, то что бы трафик до пользователей (172.16.0.0/16) пошёл через R26).

### Назначение NET идентификаторов


NET идентификатор состоит из: Authority and Format Id (AFI), Area Id, System Id и N-Selector (NSEL).

- AFI равный 49 относились к классу локальных.
- Area ID - номер области, к которой принадлежит маршрутизатор.
- System ID - это идентификатор маршрутизатора. У каждого маршрутизатора в топологии он должен быть уникальным.
- NSEL (аналог порта в протоколах транспортного уровня) всегда 00.


System Id (6 байт) получим путем добавления нулей в IPv4 адрес(4 байта) loopback-интерфейсов маршуртизаторов.
(в каждом октете добавляем что бы было три цифры, далее записываем в виде трех групп по четыре цифры)

- R23  lo0  10.3.0.1 => 010.003.000.001 => System ID 0100.0300.0001 
- R25  lo0  10.3.0.2 => 010.003.000.002 => System ID 0100.0300.0002
- R24  lo0  10.3.0.3 => 010.003.000.003 => System ID 0100.0300.0003
- R26  lo0  10.3.0.4 => 010.003.000.004 => System ID 0100.0300.0004

В итоге выбраны следующие NET:
- R23 NET 49.2222.0100.0300.0001.00
- R25 NET 49.2222.0100.0300.0002.00
- R24 NET 49.0024.0100.0300.0003.00
- R26 NET 49.0026.0100.0300.0004.00


### Настройка 

http://xgu.ru/wiki/IS-IS

Базовая настройка IS-IS:

1. Определить зоны, подготовить схему адресации (NET) для маршрутизаторов
2. Включить IS-IS на маршрутизаторе
3. Настроить NET
4. Включить IS-IS на интерфейсах
5. Изменить уровень маршрутизатора
6. Изменить уровень интерфейсов


R23

```
R23(config)#router isis
R23(config-router)#net 49.2222.0100.0300.0001.00
R23(config-router)#is-type level-1-2
```
```
R23(config)#interface ethernet 0/1
R23(config-if)#ip router isis
R23(config-if)#isis circuit-type level-1-2
```
```
R23(config)#interface ethernet 0/2
R23(config-if)#ip router isis
R23(config-if)#isis circuit-type level-1-2
```
```
R23(config)#interface loopback 0
R23(config-if)#ip router isis
R23(config-if)#isis circuit-type level-1-2
```
